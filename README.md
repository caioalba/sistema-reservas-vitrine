# Sistema de Reservas

> **Repositório vitrine.** Apenas apresentação do projeto. O código-fonte é privado. Autor: Caio Alba de Camargo.

Sistema web de agendamento de reservas de carros e salas de reunião para uso corporativo. Em uso por toda a empresa, já que qualquer colaborador pode reservar salas de reunião.

## O que faz
- Reserva de veículos e salas, com controle de horários e conflitos.
- Visão de agenda por recurso e por pessoa.
- Pensado para ser simples: qualquer colaborador reserva sem treinamento.

## Contexto
Projeto criado a partir de uma necessidade real do dia a dia do suporte de TI, desenvolvido com apoio de ferramentas de IA (Codex, Gemini, Antigravity) e validado em uso real.
